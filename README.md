## 🚀 Getting Started

### Prerequisites
- Node.js 18+ 
- npm or pnpm

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:3000` to see the application.

### Build for Production

```bash
# Build the application
npm run build

# Start production server
npm start
```

## 🔧 Customization

### Brand Colors
Update the CSS custom properties in `app/globals.css`:

```css
:root {
  --apple-blue: oklch(0.55 0.15 220);
  --apple-purple: oklch(0.45 0.12 280);
  /* Add your brand colors */
}
```

### Product Images
Replace images in the `public/` directory with your product photos.

### Content
Update product information in the component files:
- Product names and descriptions
- Technical specifications
- Pricing information
- Feature highlights
